GAME:
	TOP DOWN ZELDA LIKE
	3 LEVEL HIT EDGE OF SCREEN THEN REDRAW SCREEN AND MOVE TO NEXT LEVEL 
	BOSS ON STAGE 3 (ENEMY)

NEEDS:
	TEXT:
		HEALTHCOUNTER
		SCORE
		MENU TEXT

	BUTTONS:
		START GAME
		EXIT GAME

	STATE MACHINE:
		MENU
		LEVEL
		GAMEOVER
		WIN 

	CLASSES:

		OBJECT CLASS	
			POSX,Y
			SIZE											
		ENTITY CLASS
			BASE VARIABLES:
				HEALTH
				DAMAGE
				ETC...
			FUNCTIONS:
				TAKE DAMAGE
				SETPOS
				GETPOS
				DIE
				COLLISION
				ETC...	
			DYNAMIC ARRAY OF POINTERS TO ENTITES (PLAYER BEING INDEX 0)
			POOL OF ENTITIES THAT ARE PULLED INTO A VECTOR
			

		PLAYER CLASS
			FUNCTION OVERIDES FROM ENTITY + OWN FUNCTIONS

		ENEMY CLASS (MELEE, RANGED (IF TIME ),BOSS (HIGHER STAT MELEE))
			FUNCTION OVERIDES FROM ENTITY + OWN FUNCTIONS

		OBSTACLE CLASS(WALLS)
	MAIN:
		DRAW SCREEN AND MAIN UPDATE GAME SCREEN UPDATE LOOP
		HANDLE STATE SWITCHES

HOW:
	1.LAUNCH MENU STATE AND ALLOW GAME TO START OR EXIT
	2.DRAW SCENE 1 AND POP UP TUTRIAL TEXT
	3.REGISTER WALL COLLISIONS AND LEVEL EXIT COLLISIONS
	4.ON EXIT COLLISION REDRAW SCENE TO NEW GAME STATE AND SPAWN ENEMIES
	4.5.IF DEAD GAMEOVER
	5.CHECK IF ENEMIES ARE ALL DEAD AND OPEN EXITS
	6.REPETE UNTILL BOSS ROOM
	7.IF BOSS DEAD WIN SCREEN
	8.DISPLAY SCORE , REPLAY AND EXIT BUTTONS
